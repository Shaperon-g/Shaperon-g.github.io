Privacy Policy

This application is used only by its owner to access their own Google Drive through rclone. It is not a public service.

Data access and use

With the owner's permission, rclone accesses Google Drive file contents, file names, and metadata to perform requested file copying, backup, and synchronization operations. Depending on the commands used, it may create, modify, or delete files.

Storage and sharing

Rclone runs on the owner's computer. OAuth credentials and tokens are stored in the local rclone configuration. This application does not operate a separate server to collect Google user data. Data is not sold or used for advertising or AI model training.

Revoking access

The owner can revoke access in their Google Account settings and delete the local rclone configuration and any local copies of files.
